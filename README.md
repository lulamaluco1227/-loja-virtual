# 🛒 Loja Virtual

Projeto de loja virtual desenvolvido para praticar conceitos de desenvolvimento web, organização de dados em JSON e manipulação de elementos com JavaScript.

A aplicação apresenta produtos e permite acessar uma página com detalhes de cada item.

## 🚀 Funcionalidades

- 🛍️ Exibição de produtos
- 🔎 Visualização de detalhes dos produtos
- 💰 Exibição de preços
- 🖼️ Imagens dos produtos
- 📦 Dados armazenados em JSON
- 📱 Interface utilizando Bootstrap

## 🛠️ Tecnologias utilizadas

- HTML5
- JavaScript
- Bootstrap 5
- JSON

🎯 Objetivo
O projeto foi desenvolvido para praticar desenvolvimento front-end, manipulação do DOM, utilização de arquivos JSON e organização de uma aplicação web.
